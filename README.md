# COI Breeders

MVP mobile-first per allevatori: archivio cani, pedigree manuale fino a 5 generazioni, calcolo COI secondo Wright, elenco antenati comuni e stampa/PDF.

## Pubblicazione
Il progetto è pensato per GitHub Pages. GitHub Pages pubblica file statici direttamente da un repository; per un project site l'URL è tipicamente `https://OWNER.github.io/REPOSITORY`.

## Prossimo sviluppo
- autenticazione Google/email con Supabase
- archivio cloud multi-dispositivo
- caricamento foto pedigree
- OCR/AI multimodale con schermata di revisione
- albero genealogico grafico
- PDF professionale con logo allevatore
- gestione ID univoci degli individui e algoritmo genealogico completo per evitare doppi conteggi
- supporto ENCI/LOI e dati anagrafici estesi

## Nota genetica
Il risultato dell'MVP è calcolato solo sui dati inseriti e non deve essere considerato definitivo quando il pedigree è incompleto o contiene omonimie. Prima del rilascio produttivo va implementato il controllo rigoroso dei percorsi e del doppio conteggio degli antenati comuni.
